# DirectLauncher - Instalador Oficial

Repositório dedicado ao instalador do **DirectLauncher** (desenvolvido em Inno Setup), projetado para oferecer uma experiência de instalação moderna, limpa e automatizada para o Minecraft Java Edition.

---

## 🚀 O que este instalador oferece

* **Assistente moderno:** interface em tema escuro com azul.
* **Multilíngue:** Português (Portugal), Português (Brasil) e Inglês.
* **Página de novidades:** mostra o que mudou em cada versão antes da instalação.
* **Termos de uso:** têm de ser aceites antes de instalar.
* **Componentes opcionais:** o DirectLauncher é obrigatório e o Java 17 é opcional.
* **Download automático:** descarrega a versão mais recente do launcher do GitHub.
* **Atalhos:** criação opcional no ambiente de trabalho e no menu Iniciar.
* **Desinstalação segura:** pergunta antes de apagar os dados do launcher.

---

## 📥 Como descarregar e instalar

1. Acede à secção **Releases** deste repositório.
2. Descarrega o ficheiro `DirectLauncher_Setup.exe` da versão mais recente.
3. Executa o instalador no teu Windows e segue os passos do assistente.

### ⚠️ Aviso do Windows ao instalar

O Windows (SmartScreen) e o Microsoft Edge podem mostrar um aviso a dizer que o `DirectLauncher_Setup.exe` não é comum. Isto acontece porque o instalador não tem assinatura digital de código. **É um comportamento esperado** e não significa que o ficheiro seja perigoso.

* No Edge, clica em **Ver mais** e depois em **Manter**.
* Ao executar, se aparecer o aviso do SmartScreen, clica em **Mais informações** e depois em **Executar mesmo assim**.

Para confirmares que o ficheiro não foi alterado, compara o SHA-256 com o que aparece na página da release.

---

## 🛠️ Tecnologias utilizadas

* **Inno Setup** (script em Pascal e automação do instalador)
* **Launch4j** (empacotamento do executável Java)

---

## ⚠️ Aviso

O DirectLauncher é um launcher não oficial e não é afiliado à Mojang Studios nem à Microsoft. É necessário possuir uma cópia legítima do Minecraft Java Edition.
