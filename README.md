# DirectLauncher - Instalador Oficial

Repositório dedicado ao instalador profissional do **DirectLauncher** (desenvolvido em Inno Setup), projetado para oferecer uma experiência de instalação moderna, limpa e automatizada para o Minecraft Java Edition.

---

## 🚀 O que este Instalador Oferece:

* **Assistente Moderno (`WizardStyle=modern`)**: Interface elegante em tons de preto e azul corporativo.
* **Verificação de Dependências**: Deteta automaticamente se o Java necessário está instalado no sistema.
* **Descarregamento Dinâmico**: Integração com o GitHub para obter os ficheiros e atualizações mais recentes de forma segura.
* **Atalhos Automáticos**: Criação opcional de atalhos no ambiente de trabalho e menu iniciar com o ícone personalizado.

---

## 📥 Como Descarregar e Instalar

1. Acede à secção de **Releases** deste repositório.
2. Descarrega a versão mais recente do ficheiro `DirectLauncher_Installer.exe`.
3. Executa o instalador no teu Windows e segue os passos do assistente.

---

## 🛠️ Tecnologias Utilizadas
* **Inno Setup** (Script avançado em Pascal e automação)
* **Launch4j** (Empacotamento do executável Java)
